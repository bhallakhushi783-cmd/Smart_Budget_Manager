# 💰 Self Budget Manager

Self Budget Manager is a Python-based desktop application designed to help students manage and monitor their daily expenses.

## Features

- Add daily expenses
- Edit existing expenses
- Delete expenses
- Search expenses
- Filter expenses by category
- Set monthly budget limit
- Track remaining budget
- View spending by category
- Monthly spending charts
- Expense insights
- Export monthly expense reports
- Store data using CSV and JSON files

## Technologies Used

- Python
- Tkinter
- CSV
- JSON
- Matplotlib
- Datetime
- OS
- Math

## Categories

- Food
- Transport
- Shopping
- Bills
- Others

## Files

- `main.py` – Main application and GUI
- `expenses.csv` – Stores expense records
- `settings.json` – Stores monthly budget settings
- `summary.csv` – Stores category-wise expense summary
- `README.md` – Project documentation

## How to Run

Install the required library:

pip install matplotlib

Then run:

python main.py
